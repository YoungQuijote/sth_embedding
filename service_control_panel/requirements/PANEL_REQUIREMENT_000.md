# 示例需求

*具体内容可以自行发挥，需求表达清晰即可；下面以SPEC模式进行演示*

## Goal

任务目标

## Context

背景信息及业务上下文

## Requirements

功能需求

## Constraints

技术和业务的约束/边界

## Interface

输入输出

## Workflow

编写、验收 或 要求执行的具体工作流程

## Acceptance Criteria

验收标准

## Failure Handling

异常处理和恢复策略

## Permissisons

本次需求开发中允许的操作权限

**注意：以上仅以SPEC模式进行演示，不是每个模块都得包含，也不是只能用SPEC；需求文档的填写可自由发挥，只要需求表达清晰即可**
