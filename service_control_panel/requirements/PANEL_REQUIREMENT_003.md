# 远程环境删除与管理员改密

用户在第二轮验收后提出：远程环境应能删除，管理员应能在界面修改登录密码。

## 功能与验收

1. 远程环境卡片提供删除入口及确认弹窗。删除仅移除 Panel 环境记录、SSH 凭据和指纹，不连接/修改远端主机。
2. 可见且未卸载的引用实例阻止删除；隐藏实例仍有 queued/running 任务时也阻止删除。返回具体实例名称，提示先卸载或移除监测并等待任务结束。已卸载或已移除且无任务的实例保留历史记录，不阻止删除。
3. 删除与实例登记按同一把锁协调，部署/接入登记前重新确认环境存在，避免并发接入产生悬空引用。
4. “设置与帮助 → 修改登录密码”要求当前密码/访问令牌、新密码、确认新密码。保持单管理员 Bearer 认证，已有管理员令牌继续可用。
5. 新凭据为 16–256 位可打印 ASCII 字符，不含空格；拒绝当前密码错误、确认不一致、与旧值相同及不合规则的输入。密码不在响应或校验错误中回显。
6. 成功改密后旧凭据不能发起新的认证请求，现有短时下载票据失效，当前页面退出并要求新密码登录。正在执行的远程任务不取消；不修改 SSH/Mock 凭据。
7. 新密码仅持久保存带盐 scrypt 校验值；重启后仍有效，优先于原 PANEL_ADMIN_TOKEN/admin.token。凭据与下载票据更新原子提交，写入失败保留原凭据。

## 边界

- 仍仅支持单进程、单 worker；不增加多用户系统。
- 已通过认证并开始执行的请求可完成，后续请求必须使用新凭据。
- 主机管理员遗失凭据时可停机备份后离线重置；普通页面不提供绕过当前凭据的重置入口。
- 无需 mock 侧接口改动。
