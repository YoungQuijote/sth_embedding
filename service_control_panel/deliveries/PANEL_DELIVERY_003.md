## 可见变化

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| 删除环境 | 远程环境 → 环境卡片 → 删除环境 | 确认后删除连接配置/凭据/指纹，不操作远端；列出阻止删除的引用实例 |
| 修改密码 | 设置与帮助 → 修改登录密码 | 当前凭据、新密码、确认密码；成功后退出并使用新密码重登 |

环境有可见未卸载实例，或任何引用实例仍有 queued/running 任务时拒绝删除（包含已移除监测的实例）。已卸载或已移除监测且没有活动任务时可删除，保留实例/任务历史。部署/接入在登记锁内重新检查环境；SSH 首次记住指纹时发现环境已删除则终止。

认证保持原有单管理员 Bearer 协议。新密码是 16–256 位不含空格的可打印 ASCII 字符；原管理员令牌可以作为“当前密码”使用。新密码保存带盐 scrypt 校验值；当前已验证凭据的摘要仅在内存缓存。持久化新校验值与撤销下载票据在同一 SQLite 事务提交，失败时不切换认证状态。后续请求不能使用旧凭据，正在运行的任务及已认证请求允许完成。

## 升级及恢复

按 README 更新前后端并重启单 worker Panel。原登录凭据保持有效，直到管理员主动改密。改密后持久化校验值优先于 `PANEL_ADMIN_TOKEN` 和 `admin.token`，重启不会恢复旧密码；旧 bootstrap 文件会尝试删除，留下的文件也不生效。

忘记新密码的离线恢复流程见 README：主机管理员停机备份后删除认证记录，并重置 bootstrap 文件/环境变量，再启动。不要直接回退到旧应用并假设新密码仍有效；旧版不认识持久认证记录。删除环境只影响 Panel 记录，不能作为远端资源卸载方式。
